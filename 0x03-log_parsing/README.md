# Log Parsing

This directory contains a project focused on log parsing. The goal is to process and analyze log files to extract meaningful information.

## Project Structure

- `0-generator.py`: A script to generate random log entries.
- `0-stats.py`: The main script to parse and analyze log entries.

## Usage

```bash
./0-generator.py | ./0-stats.py
```

## Requirements

- Python 3.x
